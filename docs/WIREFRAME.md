## 2. 영역별 상세 UI 컴포넌트 규격

### [A] 상단 유틸리티 영역 (Top Utility Bar)
- **배치**: 페이지 최상단 우측 배치 (`padding: 16px 20px`)
- **공유 버튼 (Share Button)**:
  - 크기: `36px × 36px` 원형 버튼
  - 디자인: 반투명 배경 (`bg-white/10` 또는 `bg-black/10`), 중앙 공유 아이콘 배치
  - 인터랙션: 클릭 시 모바일 기기의 네이티브 `navigator.share()` 호출. 미지원 환경에서는 클립보드 복사 토스트 팝업 제공.

### [B] 프로필 헤더 영역 (Profile Header)
- **배치**: 화면 상단 중앙 정렬 (`text-align: center`, 하단 여백: `24px`)
- **아바타 이미지 (Avatar)**:
  - 규격: `80px × 80px` (모바일) ~ `96px × 96px` (데스크톱)
  - 마스크: 완전한 원형 (`rounded-full`), 테두리 링 효과 (`ring-2 ring-white/20`)
  - 대체 뷰: 이미지 미등록 시 닉네임 첫 글자 이니셜 표시
- **표시 이름 (Display Name)**:
  - 폰트: `18px ~ 20px`, `font-bold` (두껍게), 자간 `-0.02em`
- **한 줄 소개 (Bio)**:
  - 폰트: `13px ~ 14px`, `font-normal`, 줄간격 `1.5`
  - 최대 너비: `280px ~ 320px` (줄바꿈이 자연스럽게 일어나도록 제한)

### [C] 소셜 아이콘 바 (Social Icon Bar)
- **배치**: 프로필 소개글 바로 하단 (`margin-top: 14px`, `margin-bottom: 20px`)
- **스타일**:
  - 버튼 규격: `32px × 32px` 원형
  - 가로 정렬: `flex justify-center items-center gap-3`
  - 등록된 플랫폼만 동적 렌더링 (Instagram, YouTube, GitHub, X, LinkedIn, Threads, Email)
  - 호버/터치 인터랙션: 확대 애니메이션 (`scale-110`, 터치 피드백)

### [D] 링크 블록 목록 스택 (Link Blocks Stack)
- **배치**: 화면 중앙 핵심 영역, 세로 스택 레이아웃 (`gap: 12px`)
- **버튼 규격**:
  - 높이: `48px ~ 52px` (터치 대상 최소 규격 44px 이상 만족)
  - 패딩: 좌우 `16px ~ 20px`
  - 텍스트 정렬: 중앙 정렬 (`flex-1 text-center font-semibold text-sm sm:text-base`)
  - 우측 아이콘: `16px × 16px` 외부 링크(`ExternalLink`) 아이콘
- **테마별 스타일 가변성**:
  - **형태(Shape)**:
    - 알약형 (`rounded-full`)
    - 라운드형 (`rounded-2xl`, 반경 16px)
    - 각진형 (`rounded-none`, 반경 0px)
  - **채우기(Style)**:
    - 솔리드 (Solid): 테마 카드 배경색 100% 채움 + 미세한 그림자
    - 아웃라인 (Outline): 투명 배경 + 테두리 2px 선 스타일
    - 글래스 (Glass): 반투명 블러 (`backdrop-blur-md`) 배경
- **인터랙션**:
  - 호버/클릭 시 미세한 스케일 다운/업 피드백 (`hover:scale-[1.015] active:scale-[0.985]`)
  - 클릭 시 백그라운드로 클릭 수 카운트 후 새 창(`_blank`)으로 목적지 이동

### [E] 하단 브랜드 뱃지 (Footer Branding)
- **배치**: 페이지 맨 하단 (`margin-top: auto`, `padding-bottom: 24px`)
- **형태**:
  - 작고 눈에 부담스럽지 않은 알약형 뱃지 (`px-3 py-1.5 rounded-full text-xs`)
  - 문구: "✦ 마이링크로 나만의 링크 만들기"
  - 링크: 클릭 시 마이링크 서비스 소개 및 생성 페이지로 이동

## 3. 반응형 뷰포트 규칙 (Responsive Layout)

| 기기 구분 | 뷰포트 너비 | 레이아웃 동작 규칙 |
|---|---|---|
| **모바일 (기본)** | 320px ~ 480px | 화면 전체 너비(`w-full`)를 활용하며 좌우 패딩 `20px` 유지 |
| **태블릿 / 데스크톱** | 481px 이상 | 전체 페이지 중앙에 **최대 너비 420px**의 단일 카드 형태로 배치, 배경에 부드러운 그라디언트 블러 처리 |
